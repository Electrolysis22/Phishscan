About PhishScan

PhishScan combines a machine learning model with direct inspection, so one weak signal does not decide the result on its own.

Links

The address itself, how old the domain is, its HTTPS certificate, redirects, and the page content: password forms that send data elsewhere, pages that copy a known brand, hidden frames and obfuscated scripts.

Emails

The sender and Reply-To, email authentication results, pressure wording, requests for passwords or card details, links that show one address but open another, password forms, and every attachment.

Files

What the file really is regardless of its name, disguised programs, macros, remote templates, PDF scripts, risky archive contents, saved web pages, and the links and wording inside.

How to read the score

The score runs from 0 to 100 and adds up the evidence found. Below 25 looks legitimate, 25 to 49 is suspicious, and 50 or more is likely phishing. It is a risk estimate, not proof. A low score does not guarantee a file or email is safe, and this check does not replace antivirus software.
